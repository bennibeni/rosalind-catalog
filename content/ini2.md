# Variables and Some Arithmetic (Rosalind ID: INI2)

Fonte: https://rosalind.info/problems/ini2/ (Python Village)

Argomenti Rosalind: non classificato. Python Village - non fa parte del sistema di Topics ufficiale di Rosalind (riservato a Bioinformatics Stronghold/Armory).

## Descrizione
Esercizio introduttivo sulle operazioni aritmetiche di base in Python (addizione,
sottrazione, moltiplicazione, divisione, modulo, elevamento a potenza). Applica il
teorema di Pitagora.

## Given
Due interi positivi a e b, ciascuno minore di 1000.

## Return
L'intero corrispondente al quadrato dell'ipotenusa del triangolo rettangolo i cui cateti
hanno lunghezza a e b (cioè a² + b²).

## Sample Dataset
```
3 5
```

## Sample Output
```
34
```
