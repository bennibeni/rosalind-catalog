# Strings and Lists (Rosalind ID: INI3)

Fonte: https://rosalind.info/problems/ini3/ (Python Village)

Argomenti Rosalind: non classificato. Python Village - non fa parte del sistema di Topics ufficiale di Rosalind (riservato a Bioinformatics Stronghold/Armory).

## Descrizione
Esercizio introduttivo su liste e slicing di stringhe in Python (indicizzazione 0-based,
slicing con notazione `s[a:b]`, indici negativi).

## Given
Una stringa `s` di lunghezza massima 200 caratteri e quattro interi a, b, c, d.

## Return
Lo slice di questa stringa dagli indici a a b e da c a d (con uno spazio tra i due),
in modo inclusivo (cioè includendo anche gli elementi s[b] e s[d]).

## Sample Dataset
```
HumptyDumptysatonawallHumptyDumptyhadagreatfallAlltheKingshorsesandalltheKingsmenCouldntputHumptyDumptyinhisplaceagain.
22 27 97 102
```

## Sample Output
```
Humpty Dumpty
```
