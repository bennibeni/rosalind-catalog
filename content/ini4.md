# Conditions and Loops (Rosalind ID: INI4)

Fonte: https://rosalind.info/problems/ini4/ (Python Village)

Argomenti Rosalind: non classificato. Python Village - non fa parte del sistema di Topics ufficiale di Rosalind (riservato a Bioinformatics Stronghold/Armory).

## Descrizione
Esercizio introduttivo su istruzioni condizionali (if/else) e cicli (while, for) in
Python.

## Given
Due interi positivi a e b (a < b < 10000).

## Return
La somma di tutti gli interi dispari da a a b, inclusi entrambi gli estremi.

## Sample Dataset
```
100 200
```

## Sample Output
```
7500
```
