# Working with Files (Rosalind ID: INI5)

Fonte: https://rosalind.info/problems/ini5/ (Python Village)

Argomenti Rosalind: non classificato. Python Village - non fa parte del sistema di Topics ufficiale di Rosalind (riservato a Bioinformatics Stronghold/Armory).

## Descrizione
Esercizio introduttivo su lettura e scrittura di file in Python (modalità 'r'/'w'/'a',
metodi `read()`, `readline()`, `readlines()`, `split()`, `write()`).

## Given
Un file contenente al massimo 1000 righe.

## Return
Un file contenente tutte le righe con numero pari dal file originale (indicizzazione
delle righe 1-based).

## Sample Dataset
```
Bravely bold Sir Robin rode forth from Camelot
Yes, brave Sir Robin turned about
He was not afraid to die, O brave Sir Robin
And gallantly he chickened out
He was not at all afraid to be killed in nasty ways
Bravely talking to his feet
Brave, brave, brave, brave Sir Robin
He beat a very brave retreat
```

## Sample Output
```
Yes, brave Sir Robin turned about
And gallantly he chickened out
Bravely talking to his feet
He beat a very brave retreat
```
