# Counting Phylogenetic Ancestors (Rosalind ID: INOD)

Fonte: https://rosalind.info/problems/inod/

Argomenti Rosalind: Combinatorics, Phylogeny

## Descrizione
Un albero binario non radicato ha tutti i nodi interni di grado 3. Il problema chiede il
numero di nodi interni di un qualsiasi albero binario non radicato con n foglie.

## Given
Un intero positivo n (3 ≤ n ≤ 10000).

## Return
Il numero di nodi interni di un qualsiasi albero binario non radicato con n foglie.

## Sample Dataset
```
4
```

## Sample Output
```
2
```
