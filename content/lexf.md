# Enumerating k-mers Lexicographically (Rosalind ID: LEXF)

Fonte: https://rosalind.info/problems/lexf/

Argomenti Rosalind: String Algorithms

## Descrizione
Dato un alfabeto con un ordine prestabilito, il problema chiede di enumerare tutte le
stringhe di lunghezza n formabili da quell'alfabeto, in ordine lessicografico (come nel
dizionario).

## Given
Una collezione di al massimo 10 simboli che definiscono un alfabeto ordinato, e un intero
positivo n (n ≤ 10).

## Return
Tutte le stringhe di lunghezza n che possono essere formate dall'alfabeto, in ordine
lessicografico (secondo l'ordine standard dei simboli dell'alfabeto inglese).

## Sample Dataset
```
A C G T
2
```

## Sample Output
```
AA
AC
AG
AT
CA
CC
CG
CT
GA
GC
GG
GT
TA
TC
TG
TT
```
