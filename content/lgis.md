# Longest Increasing Subsequence (Rosalind ID: LGIS)

Fonte: https://rosalind.info/problems/lgis/

Argomenti Rosalind: Dynamic Programming, Genome Rearrangements

## Descrizione
Data una permutazione, una sottosequenza è una collezione dei suoi elementi presi
nell'ordine in cui appaiono. È crescente se gli elementi aumentano, decrescente se
diminuiscono. Il problema chiede la più lunga sottosequenza crescente e la più lunga
sottosequenza decrescente di una data permutazione.

## Given
Un intero positivo n ≤ 10000, seguito da una permutazione π di lunghezza n.

## Return
Una più lunga sottosequenza crescente di π, seguita da una più lunga sottosequenza
decrescente di π.

## Sample Dataset
```
5
5 1 4 2 3
```

## Sample Output
```
1 2 3
5 4 2
```
