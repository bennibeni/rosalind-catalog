# Calculating Protein Mass (Rosalind ID: PRTM)

Fonte: https://rosalind.info/problems/prtm/

Argomenti Rosalind: Computational Mass Spectrometry

## Descrizione
In un alfabeto pesato, ogni simbolo ha assegnato un peso; il peso di una stringa è la
somma dei pesi dei suoi simboli. Il peso standard di ogni amminoacido è la sua massa
monoisotopica. Il problema chiede la massa totale di una stringa proteica, sommando le
masse monoisotopiche dei residui (usando la tabella delle masse monoisotopiche).

## Given
Una stringa proteica P di lunghezza massima 1000 aa.

## Return
Il peso totale di P (consultando la tabella delle masse monoisotopiche).

## Sample Dataset
```
SKADYEK
```

## Sample Output
```
821.392
```
