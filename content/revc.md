# Complementing a Strand of DNA (Rosalind ID: REVC)

Fonte: https://rosalind.info/problems/revc/

Argomenti Rosalind: String Algorithms

## Descrizione
Nelle stringhe di DNA, 'A' e 'T' sono complementari tra loro, così come 'C' e 'G'.
Il complemento inverso (reverse complement) di una stringa `s` è la stringa ottenuta
invertendo l'ordine dei simboli di `s` e poi sostituendo ciascun simbolo con il proprio
complementare (es. il reverse complement di "GTCA" è "TGAC").

## Given
Una stringa di DNA `s` di lunghezza al massimo 1000 bp.

## Return
Il reverse complement di `s`.

## Sample Dataset
```
AAAACCCGGT
```

## Sample Output
```
ACCGGGTTTT
```
