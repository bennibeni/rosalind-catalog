# Transcribing DNA into RNA (Rosalind ID: RNA)

Fonte: https://rosalind.info/problems/rna/

Argomenti Rosalind: String Algorithms

## Descrizione
Una stringa di RNA è formata dall'alfabeto {A, C, G, U}. Data una stringa di DNA `t`
(il filamento codificante), la sua trascrizione in RNA `u` si ottiene sostituendo ogni
occorrenza di 'T' con 'U'.

## Given
Una stringa di DNA `t` di lunghezza al massimo 1000 nt.

## Return
La stringa di RNA trascritta da `t`.

## Sample Dataset
```
GATGGAACTTGACTACGTAAATT
```

## Sample Output
```
GAUGGAACUUGACUACGUAAAUU
```
